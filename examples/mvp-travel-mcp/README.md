# Travel MCP

This company-owned MCP example learns trip-relevant preferences from a verified loyalty customer, personalizes hotel ranking, and links a booking outcome to the exact context used.

No customer Epode account or plugin is required. The travel company's MCP server owns both `record_customer_context_consent` and `share_customer_context`.

```bash
EPODE_API_KEY=af_live_... npm start
```
