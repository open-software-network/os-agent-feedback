# Subscription media Fastify

This example enriches a verified subscriber profile with explicitly shared genre and viewing preferences, personalizes the feed, and records engagement against the exact decision.

The question must never request or infer sensitive characteristics. The same-origin relay accepts only the bounded Epode answer schema.

`GET /api/feed` demonstrates JSON. Authenticated `GET /agent-home` demonstrates real server-rendered HTML: the
adapter preserves the visible page and strict CSP while adding the non-executable customer-context meta marker.

```bash
EPODE_API_KEY=af_live_... npm start
```
