Epode is the agent experience and analytics layer for products. It helps companies understand every
customer—known, anonymous, or present for only one interaction—through the AI agent acting for them,
then personalize the product and measure the outcome.

The company installs Epode once. Customers do not create an Epode account, install
a plugin, or send product keys anywhere.

## The product model

| Screen | The question it answers |
| --- | --- |
| **Home** | What is happening across agent experiences on this product? |
| **Journeys** | Which agent experience paths ran, and where did they complete or stall? |
| **Customers** | What does this customer care about, and how do we know? |
| **Responses** | What context did the customer's agent share, and which journey used it? |
| **Context** | What does the experience graph elicit per task, and what does this product remember across journeys? |

Journeys, customers, and responses are linked. Setup and data controls configure collection,
permission, retention, personalization, and advertising use.

## The loop

<Steps>
  <Step title="Arrive">
    A customer agent opens the product. Humans and crawlers still receive ordinary HTML; known agent
    clients can receive a machine-readable guide at the same URL.
  </Step>
  <Step title="Ask">
    On an eligible product response, Epode can request missing customer context or expose the next
    merchant-authored need edge. The agent answers from the current task, asks the customer, reports
    no relevant context, or declines.
  </Step>
  <Step title="Learn">
    The agent sends only bounded, task-relevant need state or permissioned context. Epode records the
    journey hop, permission, provenance, confidence, allowed use, and expiry.
  </Step>
  <Step title="Personalize">
    Ranked results use the expressed need state and any separately permissioned remembered context.
  </Step>
  <Step title="Measure">
    Journey hops, product evaluations, and business outcomes become ordinary Epode session and
    interaction telemetry.
  </Step>
</Steps>

<Note>
Epode is identity-aware, never identity-inventing. The company supplies verified `accountRef` or `userRef`, a
product-owned `anonymousRef`, or no stable identity at all. Epode never discovers a person's identity from an IP,
fingerprint, prompt, or agent claim.
</Note>
