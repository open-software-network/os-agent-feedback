Epode collects structured product feedback from the **independent agents used by your customers**.
You instrument your product. Your customers do not install an Epode SDK, create an Epode account,
or identify their agent.

## The mental model

<Steps>
  <Step title="Your product responds">
    Epode's server-side SDK adds a short-lived, write-only feedback contract to selected successful responses.
    The product response never waits for Epode.
  </Step>
  <Step title="Your customer's agent uses the result">
    The agent performs the customer's real task using your API, page, or MCP tool.
  </Step>
  <Step title="The agent reports what happened">
    A feedback-aware HTTP runtime or MCP client can send one bounded report containing a summary,
    impact, findings, confidence, and any workaround.
  </Step>
</Steps>

<Note>
Epode does not identify agents. Optional customer and session references come from identifiers your
product already knows, and should be opaque—not names, emails, prompts, or task content.
</Note>
