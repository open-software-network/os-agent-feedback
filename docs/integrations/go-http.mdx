## Install

```bash
epode_artifact="$(mktemp -d)/agent-feedback-go-0.4.0.tar.gz" &&
curl -fsSL https://app.epode.ai/static/agent-feedback-go-0.4.0.tar.gz -o "$epode_artifact" &&
printf '%s  %s\n' '5d4ee89ad47d61a7d3f38dbd6320585b4e1c4de40beae12d526c3858683ad85e' "$epode_artifact" \
  | shasum -a 256 -c - &&
mkdir -p .epode/agent-feedback-go-0.4.0 &&
tar -xzf "$epode_artifact" -C .epode/agent-feedback-go-0.4.0 &&
go mod edit -replace=github.com/open-software-network/os-epode/sdk/go=./.epode/agent-feedback-go-0.4.0 &&
go mod edit -require=github.com/open-software-network/os-epode/sdk/go@v0.4.0
```

This immutable hosted archive is the bootstrap path until the public Go module tag is available. The local
`replace` keeps installation reproducible without depending on the Go proxy. The versioned `.epode`
directory prevents files removed by a later SDK release from surviving an upgrade without invoking
Go's special `vendor/` mode.

## Configure once

```go
package main

import (
    "context"
    "errors"
    "log"
    "net/http"
    "os"
    "os/signal"
    "syscall"
    "time"

    agentfeedback "github.com/open-software-network/os-epode/sdk/go"
)

func main() {
    if err := run(); err != nil { log.Fatal(err) }
}

func run() error {
    router := http.NewServeMux()
    router.HandleFunc("GET /search", searchHandler)

    feedback, err := agentfeedback.New(agentfeedback.Options{
        APIKey: os.Getenv("AGENT_FEEDBACK_KEY"),
        Include: []string{"/search", "/docs/**"},
        AccountRef: func(r *http.Request) string {
            return accountID(r.Context())
        },
        UserRef: func(r *http.Request) string {
            return userID(r.Context())
        },
        AnonymousRef: func(r *http.Request) string {
            return firstPartyVisitorID(r.Context())
        },
        CustomerRef: func(r *http.Request) string {
            return accountID(r.Context()) // durable Ask once compatibility
        },
        SessionRef: func(r *http.Request) string {
            return productJourneyID(r.Context()) // optional server-issued journey
        },
    })
    if err != nil { return err }

    instrumented := feedback.Middleware(router)
    handler := authenticateProductRequest(selectAuthorizedTenant(instrumented))
    server := &http.Server{
        Addr: ":8080", Handler: handler, ReadHeaderTimeout: 5 * time.Second,
    }
    serverErrors := make(chan error, 1)
    go func() { serverErrors <- server.ListenAndServe() }()

    signals := make(chan os.Signal, 1)
    signal.Notify(signals, syscall.SIGINT, syscall.SIGTERM)
    defer signal.Stop(signals)

    var serveErr error
    select {
    case <-signals:
    case err := <-serverErrors:
        if !errors.Is(err, http.ErrServerClosed) { serveErr = err }
    }

    serverContext, cancelServer := context.WithTimeout(context.Background(), 5*time.Second)
    serverErr := server.Shutdown(serverContext)
    cancelServer()
    feedbackContext, cancelFeedback := context.WithTimeout(context.Background(), 5*time.Second)
    feedbackErr := feedback.Shutdown(feedbackContext)
    cancelFeedback()
    return errors.Join(serveErr, serverErr, feedbackErr)
}
```

Authentication must wrap and execute before Epode. Go middleware cannot observe a context created by
an inner handler with `r.WithContext`, so never place the feedback middleware outside authentication.
Account and user references must come from verified auth; the anonymous reference must be a product-owned
first-party visitor ID. A session reference is safe only when server/product state already proves the journey.
Never read these values from names, emails, prompts, caller fields, or agent arguments.

## Server-rendered HTML

Finite HTML bodies on included routes receive the embedded contract. Responses larger than the capture
limit, streams detected through `Flush`, and unsafe bodies pass through byte-for-byte.

The default capture limit is 1 MiB. Set `MaxResponseBodyBytes` to another positive value when needed.

## Route patterns and caching

In `Include`/`Exclude` patterns, `*` matches exactly one path segment and `**` matches any depth
(`/docs/*` matches `/docs/guide` but not `/docs/deep/nested/page`; use `/docs/**` for the latter).

`CacheMode` controls how instrumentation interacts with HTTP caching. The default `CacheSafe` skips
responses that declare a shared cache policy (`public`, `max-age`, `s-maxage`, `immutable`). Use
`CachePrivate` only when replacing shared caching with `private, no-store` is intentional, or
`CacheRequest` to instrument only requests that opt in with the `Agent-Feedback-Request: 1` header. Request
mode adds `Vary: Agent-Feedback-Request` to both variants so shared caches keep them separate.
Eligible ordinary 2xx `GET` and `HEAD` responses also advertise a same-path-and-query `Link` for one
authenticated Companion refetch; redirects and non-safe methods never advertise it.

## Verify

Send one API and one HTML request, then confirm the response contract and the Setup telemetry status.
Call `Shutdown` during graceful server shutdown so queued telemetry can flush.

## Customer-agent coverage

Your Go middleware creates the HTTP/HTML feedback contract; it cannot make an independent customer agent act on
it. For reliable Codex and Claude Code handling, customers install [Epode Companion](/integrations/companion)
once for all Epode-instrumented products. This is a user-side plugin, not another company package or product key.
