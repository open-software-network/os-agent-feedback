## Install

```bash
python -m pip install https://app.epode.ai/static/agent_feedback-0.2.0-py3-none-any.whl
```

Python 3.10 or newer is required.

## Configure once

Wrap the completed ASGI app:

```python
import os
from fastapi import FastAPI
from agent_feedback import AgentFeedbackASGI

app = FastAPI()

@app.get("/search")
async def search_endpoint(q: str):
    return {"results": await search(q)}

def customer_ref(scope):
    # Derive a stable, opaque account or tenant ID from your product's own
    # authentication. A raw ASGI scope has no such key by default; populate
    # scope["state"] (or read your session/auth header) in your auth middleware.
    return scope.get("state", {}).get("account_id")

app = AgentFeedbackASGI(
    app,
    api_key=os.environ["AGENT_FEEDBACK_KEY"],
    include=("/search", "/docs/*"),
    customer_ref=customer_ref,  # required for durable Ask once; optional otherwise
)
```

## Server-rendered HTML

The same wrapper injects the machine-readable contract into finite HTML responses on included routes.
JSON objects retain their existing shape and add `_agentFeedback`.

## Route patterns and caching

In `include`/`exclude` patterns, `*` matches one path segment and `**` matches any depth. `cache_mode`
mirrors the Node SDK: the default `"safe"` skips responses that declare a shared cache policy, `"private"`
replaces shared caching with `private, no-store` deliberately, and `"request"` instruments only requests
that opt in with the `Agent-Feedback-Request: 1` header. Request mode adds
`Vary: Agent-Feedback-Request` so shared caches keep ordinary and opted-in responses separate.
Eligible ordinary 2xx `GET` and `HEAD` responses also advertise a same-path-and-query `Link` for one
authenticated Companion refetch; redirects and non-safe methods never advertise it.

## Verify

Send a real request to an included route and inspect the response:

```bash
curl -sS 'https://your-product.example/search?q=epode-test' | jq '._agentFeedback'
```

For the full automated check, run the integration doctor. It ships inside the Node SDK tarball (it is not on
the npm registry), so any stack can run it with a throwaway install:

```bash
npm install https://app.epode.ai/static/agent-feedback-node-0.2.0.tgz
npx agent-feedback-doctor --url https://your-product.example/search?q=epode-test
```

Then confirm **Setup** shows telemetry. A generic HTTP client does not automatically prove agent use;
the interaction becomes confirmed when its feedback capability returns.

## Customer-agent coverage

Your ASGI middleware creates the HTTP/HTML feedback contract; it cannot make an independent customer agent act
on it. For reliable Codex and Claude Code handling, customers install
[Epode Companion](/integrations/companion) once for all Epode-instrumented products they use. This is a
user-side plugin, not another Python package, account, or product key.
