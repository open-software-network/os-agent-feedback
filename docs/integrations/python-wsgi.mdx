## Configure once

```python
import os
from flask import Flask, jsonify, request
from agent_feedback import AgentFeedbackWSGI

app = Flask(__name__)

@app.get("/search")
def search_endpoint():
    return jsonify(results=search(request.args.get("q", "")))

instrumented_app = AgentFeedbackWSGI(
    app.wsgi_app,
    api_key=os.environ["AGENT_FEEDBACK_KEY"],
    include=("/search", "/docs/*"),
    account_ref=lambda environ: environ.get("product.account_id"),
    user_ref=lambda environ: environ.get("product.user_id"),
    anonymous_ref=lambda environ: environ.get("product.first_party_visitor_id"),
    customer_ref=lambda environ: environ.get("product.account_id"),  # durable Ask once compatibility
    session_ref=lambda environ: environ.get("product.journey_id"),  # optional server-issued journey
)
app.wsgi_app = ProductTenantAuthMiddleware(instrumented_app)
```

The authentication wrapper is intentionally outermost so it establishes the verified account or
user and product-owned visitor/journey context before Epode resolves the extractors. Never populate those
values from names, emails, prompts, caller fields, or agent arguments.

The WSGI adapter buffers only responses with a declared size of at most 1 MiB. JSON objects receive
`_agentFeedback`, HTML receives a machine-readable link, and arrays or scalar JSON use the
`Agent-Feedback` response header. Unknown-size, oversized, write-callable, and streaming responses pass
through without instrumentation. Lazy WSGI iterators that call `start_response` on first iteration are
supported.

With `cache_mode="request"`, only callers sending `Agent-Feedback-Request: 1` receive a contract. The
middleware adds `Vary: Agent-Feedback-Request` to ordinary and opted-in responses so a shared cache cannot
hide the opted-in request.
Eligible finite ordinary 2xx `GET` and `HEAD` responses also advertise a same-path-and-query `Link` for one
authenticated Companion refetch; redirects and non-safe methods never advertise it.

## Server-rendered HTML

Included finite HTML pages receive the same machine-readable link as the other adapters, and Epode
recalculates `Content-Length`. Streaming or unknown-size HTML remains byte-for-byte untouched.

Decode the base64url header only in a trusted agent runtime. Do not expose or reuse the company product key.

## Customer-agent coverage

Your WSGI middleware creates the response-header feedback contract; it cannot make an independent customer
agent act on it. For reliable Codex and Claude Code handling, customers install
[Epode Companion](/integrations/companion) once for all Epode-instrumented products. This is a user-side plugin,
not another company package or product key.
